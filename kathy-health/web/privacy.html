Privacy

Kathy’s Health stores medications, symptoms, vitals, appointments, contacts, and notes in this device’s browser storage (localStorage).

Family alert SMS opens the phone’s Messages app with a pre-filled text to numbers you saved. An optional webhook URL you configure can receive alert JSON over HTTPS.

Import notes only uses text you paste. Export backup creates a file you choose where to keep (for example OneDrive).

Clearing site data, or Erase all data in Settings, removes the local copy.
