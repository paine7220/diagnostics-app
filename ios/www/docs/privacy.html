Privacy Policy

Auto/Truck Diagnostics for Dummies

This build stores cases locally on the device unless you export them. Media files stay on the device unless you deliberately export them.

This app does not send data to a third-party cloud by default; all processing happens on-device. If you later add external APIs, you must update this policy and your in-app disclosure before publishing.

Data categories that may be processed by the app include vehicle details, manually entered DTCs, symptoms, notes, photos, audio, video, and device-local case history. Use only the data necessary for diagnostics.

Use Clear Saved Case in the Results section to delete the locally stored case. Exported report files that you saved elsewhere must be deleted by you.
