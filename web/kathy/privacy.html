Privacy

Care notes, medications, and vitals stay in this device’s browser storage unless you export a backup.

When a low-sugar check-in times out (or help is requested), the app sends an alert JSON payload to the webhook URL you configure. That service (for example the included Cloudflare worker with Twilio) can text family automatically.

Family phone numbers you enter are included in that alert payload so the webhook can deliver SMS.

Import notes only uses text you paste. Clearing site data or Erase all data removes the local copy.
