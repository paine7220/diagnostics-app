Use on a computer
Same app on a PC. Useful when you want a bigger screen or an offline folder.
  1. Fastest: on the computer, open Chrome or Edge and go to the same page you are reading now. Bookmark it.
  2. Offline folder: on the computer open GitHub → Code → Download ZIP. Unzip it. Double-click GET_ON_COMPUTER.bat (Windows) or web/index.html (any computer).
  3. Windows app window: after the unzip, install Node.js LTS, then double-click windows\START_APP_FOR_TESTING.bat. For a Setup EXE, use windows\BUILD_WINDOWS_INSTALLER.bat.
