Use this app on a computer

Same codes, rebuild path, and how-to jobs. No phone required after the copy is on the PC.

1. Fastest — open it in the computer’s browser

  1. Sit at the computer. Open Chrome or Microsoft Edge.
  2. Go to the GitHub project: https://github.com/paine7220/diagnostics-app
  3. Or paste this page if you already have it working on the phone. Bookmark it on the computer.
  4. This is the same app. Type a code or open How-to Jobs. It does not need a scan tool.

2. Offline folder — keep a copy on the hard drive

  1. On the computer, open https://github.com/paine7220/diagnostics-app
  2. Click the green Code button, then Download ZIP.
  3. If you are on this transfer branch, this ZIP is the same copy: download the computer-transfer branch ZIP.
  4. Unzip the folder. You should see GET_ON_COMPUTER.bat next to a web folder.
  5. Windows: double-click GET_ON_COMPUTER.bat. The app opens in your browser.
  6. Any computer: open the web folder and double-click index.html (or OPEN_ON_COMPUTER.bat on Windows).
  7. You can copy that web folder to a USB stick and open it on another PC the same way.

3. Windows desktop app

  1. Install Node.js LTS from https://nodejs.org if it is not already installed. Reboot if the installer asks.
  2. From the unzipped project, double-click windows\START_APP_FOR_TESTING.bat. The first run installs Electron, then a desktop window opens.
  3. For a one-click Setup EXE and a Portable EXE, double-click windows\BUILD_WINDOWS_INSTALLER.bat. Output lands in windows\dist\.
  4. Azure Trusted Signing stays in windows\package.json. Without Azure credentials the bat file builds an unsigned installer you can still run locally.

4. Download the packed computer copy from GitHub Actions

  1. On the computer, open the repo → Actions → workflow Computer copy.
  2. Open the latest green run.
  3. Download ATDD-computer-copy-1.2.0. Unzip it. Double-click OPEN_ON_COMPUTER.bat or index.html.
  4. If the Windows installer job finished, also download ATDD-windows-1.2.0 for the Setup EXE and Portable EXE.

What transfers

Code lookup, every bundled DTC playbook, engine rebuild stages, and the how-to jobs (starter through 4WD axles). Saved cases stay on that computer. This is not live OBD and not a factory shop manual.
